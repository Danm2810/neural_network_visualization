What do the bits mean?

Think of weights as the network’s adjustable knobs. Fewer bits give those knobs fewer possible settings. We test whether the network can still make good guesses.

1 bittwo weight levels*4 bits16 possible levels8 bits256 possible levels32 bitsfull precision

*The source’s binary rule uses a scale per tensor; exactly zero weights can remain zero. Only convolution weights are quantized. Dense layers and stored master weights remain full precision. Smaller bit counts here do not mean the saved model is smaller by that same ratio.
